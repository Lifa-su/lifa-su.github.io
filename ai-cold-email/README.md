# AI 冷启动邮件生成器 ✉️

基于 DeepSeek API 的 AI 冷邮件/开发信生成工具，纯前端单页应用。

## 功能

- **多场景支持** — 销售开发信、合作邀请、求职、投资人联系、媒体PR
- **A/B 测试版本** — 同时生成 2-3 个不同风格的邮件版本
- **邮件评分** — 打开率、回复率预测评分
- **主题行优化** — 8 种不同风格的主题行建议（提问式、数据驱动、好奇心等）
- **跟进邮件序列** — 自动生成 3 封递进式跟进邮件（3天/7天/14天）
- **一键复制/导出** — 单封复制、单封导出、全部导出
- **多语言** — 支持中文、英文、双语生成
- **多语气** — 专业正式、友好亲切、简洁直接、创意独特

## 使用

1. 用浏览器打开 `index.html`
2. 输入你的 DeepSeek API Key（[获取 API Key](https://platform.deepseek.com/)）
3. 填写目标公司/联系人信息
4. 选择场景、语言、语气
5. 点击「生成邮件」

## 技术栈

- 纯前端：HTML + CSS + JavaScript（无框架依赖）
- AI：DeepSeek Chat API (`deepseek-chat`)
- 响应式设计，支持桌面和移动端
