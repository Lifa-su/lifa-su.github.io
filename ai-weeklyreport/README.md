# WeeklyAI — AI 周报/日报生成器

5分钟搞定工作汇报。输入工作要点，AI 帮你生成专业的日报/周报。

## 功能

- 🤖 DeepSeek AI 驱动，流式输出
- 📋 三种模板：简洁版 / 详细版 / OKR版
- 🌐 中英文双语支持
- 📄 一键复制富文本 / 复制 Markdown / 导出 .md 文件
- 📱 响应式设计，手机电脑都能用
- 🔒 API Key 仅存浏览器本地，隐私安全

## 使用

1. 用浏览器打开 `index.html`
2. 设置 DeepSeek API Key（[获取地址](https://platform.deepseek.com/api_keys)）
3. 输入工作要点 → 选择报告类型和模板 → 点击生成

## 技术栈

纯前端单页应用，无需后端。HTML + CSS + JavaScript。
