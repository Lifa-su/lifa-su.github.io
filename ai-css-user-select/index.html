CSS user-select 演示工具

交互式体验五种 user-select 值的效果 — 试试在每个区域中选择文本

💡 用鼠标拖选下方文本，体验不同效果
none

user-select: none

试试选中这段文字 — 你会发现完全无法选中任何内容。这就是 user-select: none 的效果，文本不可被选择。适用于不希望用户复制的 UI 元素。
📌 适用场景：按钮文字、图标标签、拖拽手柄、游戏界面、防止误选的导航栏、工具栏文字
user-select: none;
-webkit-user-select: none;
auto

user-select: auto

这是浏览器的默认行为。文本可以正常选中，就像你平时在网页上选择文字一样。auto 值会根据元素类型自动决定是否可选。
📌 适用场景：普通文本内容、文章正文、默认网页行为 — 通常不需要显式设置，这是浏览器默认值
user-select: auto;
text

user-select: text

这段文字可以被自由选中。user-select: text 明确允许文本选择，即使父元素设置了 none，子元素也可以用 text 覆盖，恢复选择能力。
📌 适用场景：在 none 容器内需要可选的代码片段、错误信息、序列号、需要复制的关键内容
user-select: text;
-webkit-user-select: text;
all

user-select: all

点击这段文字试试 — 只需单击一次，整段文本就会被全部选中！user-select: all 让用户无需拖拽，一次点击即可选中所有内容，非常适合需要整体复制的场景。
📌 适用场景：命令行代码、API Key、Token、序列号、邀请链接 — 任何需要一键复制的完整文本
user-select: all;
-webkit-user-select: all;
contain

user-select: contain

在这个区域内选择文本时，选择范围会被限制在此容器内，不会扩展到外部元素。注意：此属性浏览器支持有限，目前主要 IE/Edge (旧版) 支持，现代浏览器可能表现为 text。
📌 适用场景：富文本编辑器、独立内容区块、嵌入式组件 — 防止选择溢出到周围内容
user-select: contain;
