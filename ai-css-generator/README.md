# AI CSS Generator ✨

AI驱动的CSS代码生成器 — 描述你想要的效果，AI帮你写CSS。

## 功能

- **🤖 AI生成CSS** — 输入自然语言描述，通过DeepSeek API生成CSS+HTML代码，实时预览
- **🎨 渐变生成器** — 线性/径向/锥形渐变，自由添加颜色节点，随机生成
- **🎬 动画生成器** — 10种预设动画（弹跳、脉冲、抖动、旋转等），可调时长/缓动/次数
- **📐 布局生成器** — Flexbox/Grid布局可视化配置，实时预览

## 使用

1. 直接用浏览器打开 `index.html`
2. 输入你的 [DeepSeek API Key](https://platform.deepseek.com/)（AI生成功能需要）
3. 选择功能标签页，开始生成CSS

## 技术栈

- 纯前端：HTML + CSS + JavaScript（单文件，无依赖）
- AI：DeepSeek Chat API
- UI：暗色主题，渐变/动画/玻璃拟态效果

## API Key

AI生成功能需要DeepSeek API Key，在页面顶部输入即可。Key保存在浏览器localStorage中。

渐变、动画、布局生成器无需API Key，可离线使用。
