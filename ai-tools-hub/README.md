## ✨ 特性

- 🌙 现代深色主题，流光渐变设计
- 🔍 实时搜索，按名称或描述过滤
- 🏷️ 四大分类筛选：开发 / 设计 / 写作 / 商业
- 📱 完全响应式，适配桌面、平板、手机
- ⚡ 纯静态单页，零依赖，即开即用
- 🎨 卡片悬浮动效，流畅交互体验

## 🚀 使用

直接在浏览器中打开 `index.html` 即可：

```bash
open index.html
```

或部署到任意静态托管服务（GitHub Pages、Vercel、Netlify 等）。

## 📁 项目结构

```
ai-tools-hub/
├── index.html   # 单页应用（HTML + CSS + JS 全内联）
└── README.md    # 项目说明
```

## 🔗 自定义链接

编辑 `index.html` 中 `tools` 数组的 `link` 字段，将 `#tool-name` 替换为实际部署地址：

```javascript
{ name:"AI Translator", ..., link:"https://your-domain.com/ai-translator/" }
```
