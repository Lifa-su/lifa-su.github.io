📖 About CSS Letter Spacing

The CSS letter-spacing property controls the space between characters in text. It's a powerful typography tool that can dramatically change the feel of your design.

Common Use Cases

  • Headings: Slight positive spacing (1-3px) adds elegance and readability to large text
  • Body text: Small adjustments (0-0.5px) can improve readability for certain fonts
  • Logos & brands: Wide spacing (3-10px) with uppercase creates a modern, luxury feel
  • Navigation: Moderate spacing (1-2px) with uppercase for clean menu items
  • Negative spacing: Tighter text (-0.5 to -1px) for compact, bold headlines

Best Practices

  • Use em units for scalable spacing that adapts to font size
  • Avoid extreme values that hurt readability
  • Test across different screen sizes and fonts
  • Pair with appropriate word-spacing and line-height
  • Consider accessibility — too tight or too wide spacing reduces readability

Browser Support

letter-spacing is supported in all modern browsers including Chrome, Firefox, Safari, Edge, and Opera. It has been part of CSS since CSS1.
