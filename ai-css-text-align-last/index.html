About text-align-last

The text-align-last CSS property sets how the last line of a block or a line before a forced line break is aligned. It works best with text-align: justify.

  • auto — Last line aligned per text-align value (default)
  • start — Aligned to the start edge of the line box
  • end — Aligned to the end edge of the line box
  • left — Aligned to the left edge
  • right — Aligned to the right edge
  • center — Centered within the line box
  • justify — Last line is also justified like other lines

Browser support is excellent across all modern browsers.
