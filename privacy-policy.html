Privacy Policy

Last updated: February 26, 2026 · Applies to all Lifa AI Tools Chrome extensions

🔒 The Short Version

  • We do not collect any personal data
  • We do not use cookies or tracking technologies
  • We do not send any data to external servers
  • All processing happens locally in your browser

Extensions Covered

This privacy policy applies to the following Chrome extensions published by Lifa AI Tools:

⚡ Quick AI Toolbox
🔍 SEO Meta Checker
🎨 AI Color Picker
✍️ AI Writing Helper
🛠️ CSS Inspector

Data Collection

Our extensions do not collect, store, or transmit any personal information. Specifically, we do not collect:

  • Names, email addresses, or any personally identifiable information
  • Browsing history or visited URLs
  • Search queries or form inputs
  • IP addresses or geolocation data
  • Device identifiers or fingerprints

Cookies & Tracking

Our extensions do not use cookies, web beacons, pixels, or any other tracking technologies. We do not participate in any advertising networks or analytics platforms within our extensions.

Local Processing

All functionality provided by our extensions runs entirely within your browser. For example:

  • Quick AI Toolbox — Displays a curated list of AI tool links stored locally in the extension. No external requests are made until you choose to visit a tool.
  • SEO Meta Checker — Reads the current page's HTML meta tags directly from the DOM. Analysis is performed locally; no page data is sent anywhere.
  • AI Color Picker — Uses browser APIs to pick colors from the visible page. Color values are processed and displayed locally.
  • AI Writing Helper — Provides text enhancement options via the right-click context menu. Text processing occurs within the extension.
  • CSS Inspector — Reads computed CSS styles from page elements using browser APIs. All inspection happens locally.

Permissions

Our extensions request only the minimum permissions necessary to function. Each extension's required permissions are listed in its Chrome Web Store listing. We never request access to data beyond what is needed for the extension's core features.

Third-Party Services

Our extensions do not integrate with or send data to any third-party services, APIs, or analytics platforms. When an extension provides links to external websites (such as Quick AI Toolbox), clicking those links is your choice and those websites have their own privacy policies.

Data Storage

Some extensions may store user preferences (such as display settings or recently used tools) using Chrome's local storage API (chrome.storage.local). This data:

  • Is stored only on your device
  • Is never transmitted to any server
  • Can be cleared by uninstalling the extension

Children's Privacy

Our extensions do not knowingly collect any information from anyone, including children under the age of 13. Since we collect no data at all, there is no risk of children's data being collected.

Changes to This Policy

If we make changes to this privacy policy, we will update the "Last updated" date at the top of this page. We encourage you to review this page periodically. Any significant changes to data practices would also be reflected in the extension update notes on the Chrome Web Store.
